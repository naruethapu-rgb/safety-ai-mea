**ระบบฐานข้อมูลและสืบค้นเอกสารความปลอดภัยอัจฉริยะ (Offline 100% / Local Windows 10)**

---

## 🚀 วิธีเปิดใช้งานโปรแกรม (คลิกเดียว)
1. ดับเบิลคลิกไฟล์ **`run_app.bat`**
2. ระบบจะเปิดหน้าต่างเบราว์เซอร์เข้าสู่ Dashboard อัตโนมัติที่ `http://localhost:8501`

---

## 📁 โครงสร้างโฟลเดอร์เอกสาร
คุณสามารถนำไฟล์ PDF มาวางในโฟลเดอร์ตามหมวดหมู่ได้ตลอดเวลา:
- `documents/Accidents_Personnel/` — รายงานอุบัติเหตุเกี่ยวกับบุคคล/พนักงาน
- `documents/Accidents_Road/` — รายงานอุบัติเหตุยานพาหนะและจราจร
- `documents/WI/` — คู่มือขั้นตอนการปฏิบัติงานด้านความปลอดภัย (Work Instructions)
- `documents/Work_Permit/` — ใบอนุญาตทำงานอันตราย (Hot Work, Confined Space ฯลฯ)
- `documents/Other/` — เอกสารความปลอดภัยและสิ่งแวดล้อมอื่นๆ

> **มาตรการความปลอดภัย:** ระบบเปิดอ่านไฟล์แบบ Read-Only เท่านั้น จะไม่มีการแก้ไข ดัดแปลง หรือลบไฟล์ PDF ต้นฉบับโดยเด็ดขาด

---

## 🌟 ฟังก์ชันหลักบนหน้าจอ (ภาษาไทย 100%)
1. 🔍 **ค้นหาเอกสาร (Full-Text Search):** ค้นหาคำสำคัญภาษาไทยและอังกฤษแบบแยกคำแม่นยำสูง (เช่น *ที่อับอากาศ, สารเคมี, PPE, Forklift, WI-SAF-002*) พร้อมระบุชื่อไฟล์และเลขหน้าที่พบ
2. 📖 **เปิดดูข้อความต้นฉบับ (Document Reader):** เลือกดูข้อความที่สกัดจากหน้าใดก็ได้แบบ 100%
3. 🔄 **สแกนและซิงค์เอกสาร (Sync & Ingestion):** กดปุ่มสแกนโฟลเดอร์เพื่อนำเข้าไฟล์ใหม่ ตรวจจับไฟล์ซ้ำ (SHA-256) และอัปเดตไฟล์ที่มีการเปลี่ยนแปลง
4. 💾 **สำรองฐานข้อมูล (Database Backup):** สำรองข้อมูลแบบออนไลน์ได้ทันทีโดยไม่ต้องปิดโปรแกรม เก็บไว้ใน `database/backups/`
